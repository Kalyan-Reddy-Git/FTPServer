NetTransfer – Multi-Protocol File Transfer System

Simple, Dynamic, and Secure File Transfer (FTP • FTPS • SFTP)

NetTransfer connects directly to remote file servers using standard Application Layer protocols. Register a client account with your own credentials to receive automatically provisioned, isolated FTP storage. Manage files, navigate directory hierarchies, upload and download data, create folders, and rename items over standard FTP, encrypted FTPS (TLS/SSL), or secure SFTP (SSH-2.0).
